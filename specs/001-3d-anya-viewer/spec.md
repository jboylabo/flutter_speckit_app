# Feature Specification: 3D アーニャビューア

**Feature Branch**: `001-3d-anya-viewer`

**Created**: 2026-09-08

**Status**: Implemented (MVP)

**Input**: User description: "3Dアーニャを作る / 使用するライブラリ: flutter_3d_controller / 画像: spy-family.net の chara_anya_1.png"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 3D アーニャを表示して自由に眺める (Priority: P1)

アプリを起動すると 3D のアーニャが画面に表示される。指でドラッグすると視点が回り、ピンチで拡大縮小できる。

**Why this priority**: 「3D アーニャが出る」ことがこの機能の存在理由であり、これ単体でデモとして成立する。

**Independent Test**: アプリを起動し、キャラクターが描画されること、ドラッグ / ピンチで見え方が変わることを目視で確認できる。

**Acceptance Scenarios**:

1. **Given** アプリが起動している, **When** 初期表示が完了する, **Then** アーニャの 3D モデルが画面中央に表示される
2. **Given** モデルが表示されている, **When** 画面を左右にドラッグする, **Then** モデルが左右に回転して別の角度が見える
3. **Given** モデルが表示されている, **When** ピンチアウトする, **Then** モデルが拡大表示される
4. **Given** モデルの読み込みが完了していない, **When** 読み込み中である, **Then** 進捗が分かるインジケータが表示される

---

### User Story 2 - アニメーションを再生する (Priority: P2)

モデルに含まれるアニメーション (回転 / ジャンプ) を選び、再生・一時停止・停止できる。

**Why this priority**: 静止した 3D より動くほうがデモとしての価値が高いが、表示 (US1) が無いと成立しない。

**Independent Test**: アニメーション一覧が表示され、選択して再生ボタンを押すとモデルが動き出すことを確認できる。

**Acceptance Scenarios**:

1. **Given** モデルの読み込みが完了している, **When** アニメーション一覧を開く, **Then** モデルが持つアニメーション名が列挙される
2. **Given** アニメーションを選択している, **When** 再生ボタンを押す, **Then** モデルがそのアニメーションで動き続ける
3. **Given** 再生中である, **When** 一時停止ボタンを押す, **Then** モデルはその姿勢で止まる
4. **Given** 再生中である, **When** 停止ボタンを押す, **Then** モデルは初期姿勢に戻る
5. **Given** モデルがアニメーションを持たない, **When** 画面を開く, **Then** 再生系の操作は無効化され、その旨が分かる

---

### User Story 3 - 視点をワンタップで切り替える (Priority: P3)

正面 / 斜め / 俯瞰 / アップのプリセット視点に切り替えられ、リセットで初期視点に戻せる。自動回転の ON/OFF も切り替えられる。

**Why this priority**: 手動操作 (US1) でも代替できるため優先度は低いが、操作を知らない人でも立体であることを理解できる。

**Independent Test**: 各プリセットを押すと視点が変わり、リセットで初期状態に戻ることを確認できる。

**Acceptance Scenarios**:

1. **Given** モデルが表示されている, **When** 「斜め」を押す, **Then** 斜め方向からの視点に切り替わる
2. **Given** 視点を変更した後, **When** リセットを押す, **Then** 初期の正面視点に戻る
3. **Given** 自動回転がオフである, **When** 自動回転をオンにする, **Then** モデルが一定速度で回り続ける

---

### Edge Cases

- モデルファイルが未生成 / 見つからない場合、失敗が分かるメッセージと復旧手順 (生成コマンド) を表示し、再読み込みできる
- モデルの読み込みに失敗した場合、エラー内容と再試行手段を提示する
- モデルがアニメーションを持たない場合、再生系 UI を無効化する
- 画面回転やサイズ変更が起きても表示が破綻しない
- 3D 描画には Flutter GPU の有効化が必要なため、プラットフォーム設定が欠けていると描画されない (iOS は `Info.plist`、Android は `AndroidManifest.xml` で有効化する)

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは起動時に 3D アーニャのモデルを読み込み、画面に表示しなければならない
- **FR-002**: ユーザーはドラッグ操作でモデルを任意の角度から見られなければならない
- **FR-003**: ユーザーはピンチ操作で拡大縮小できなければならない
- **FR-004**: システムは読み込み中に進捗が分かる表示を出さなければならない
- **FR-005**: システムは読み込み失敗時にエラー内容・復旧手順・再試行手段を提示しなければならない
- **FR-006**: システムはモデルが持つアニメーション名の一覧を取得して提示しなければならない
- **FR-007**: ユーザーはアニメーションを選択して再生・一時停止・停止できなければならない
- **FR-008**: ユーザーは 4 種類のプリセット視点と初期視点へのリセットを選べなければならない
- **FR-009**: ユーザーは自動回転を ON/OFF できなければならない
- **FR-010**: システムはネットワーク接続なしで 3D モデルを表示できなければならない (モデルはアプリ内アセット)
- **FR-011**: 3D モデルは元画像から再生成可能でなければならない (生成手順がリポジトリに含まれる)

### Key Entities

- **アーニャモデル**: 表示対象の 3D アセット。ジオメトリ (立ち姿の板 + 台座)、テクスチャ (元画像)、アニメーション定義を持つ
- **アニメーション**: モデルに含まれる動きの定義。名前で識別し、再生状態 (再生中 / 一時停止 / 停止) を持つ
- **カメラ視点**: 水平角・垂直角・距離の組。プリセットとして名前付きで保持する

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: アプリ起動から 3 秒以内にアーニャが表示される
- **SC-002**: ドラッグ・ピンチ操作に対し、体感で引っかかりなく (毎秒 30 コマ以上相当) 追従する
- **SC-003**: 操作説明なしで、初見のユーザーが 10 秒以内に視点を変える操作に成功する
- **SC-004**: 機内モード (ネットワーク遮断) でも表示・操作がすべて成立する
- **SC-005**: モデルが無い状態で起動しても、画面上の案内だけで復旧手順にたどり着ける

## Assumptions

- 用途は個人の学習・デモであり、ストア配信や再配布は対象外とする
- 原作 (SPY×FAMILY) のキャラクター画像は著作物であるため、取得した画像および派生モデルはリポジトリに含めず、各自のローカルで生成する
- 単一の 2D 画像からは立体メッシュを起こせないため、3D 表現は「画像をテクスチャにした立体スタンディ (板 + 台座)」とする
- 対象プラットフォームは iOS と Android。動作確認は iOS シミュレータで行う
- 3D 描画には `flutter_scene` (Flutter GPU / Impeller によるネイティブ描画) を用いる。WebView は使わないため iOS のネイティブ依存 (CocoaPods) は発生しない
- モデル生成には Python と Pillow が利用できる環境を前提とする
